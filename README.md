# 커피 룰렛

참여자가 고른 음료 가격에 비례해 룰렛 칸과 당첨 확률이 커지는 반응형 웹 게임입니다. 기본 멤버를 참여/제외할 수 있고, 당첨 횟수와 누적 결제 금액을 기기 안에 기록합니다.

## 실행 방법

1. 압축을 풉니다.
2. `index.html`을 Chrome 또는 Edge로 엽니다.
3. 별도의 설치나 서버 실행은 필요하지 않습니다.

IntelliJ에서는 폴더를 연 뒤 `index.html`을 우클릭하고 **Open In > Browser**를 선택하면 됩니다.

## 규칙

- 참여자는 2~10명입니다.
- 당첨 확률은 `개인 음료 가격 / 전체 음료 가격 합계`로 계산합니다.
- 가격을 바꾸면 룰렛의 칸 크기가 즉시 변경됩니다.
- 음료 칸을 누르면 사진 메뉴판 기준 메뉴·사이즈·온도를 선택할 수 있고 가격이 자동 입력됩니다.
- 샷 또는 헤이즐넛/바닐라 시럽을 추가하면 각각 500원이 자동 반영됩니다.
- 룰렛 결과는 브라우저의 난수 생성 기능을 사용합니다.
- 당첨자는 참여자 전체의 주문 합계를 결제한 것으로 기록됩니다.
- 히스토리는 실행한 휴대폰 또는 PC의 브라우저에 저장됩니다. 다른 기기와 자동 동기화되지는 않습니다.

## 파일

- `index.html`: 화면, 디자인, 룰렛 계산 및 회전 기능이 모두 들어 있습니다.
